# D-Verify — GDMO Cyber-Reputation Platform

> **The Shield of Dubai's Narrative** — Real-time AI-powered misinformation detection, community-driven verification, and government-grade counter-intelligence.

---

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Open in browser
# http://localhost:5173
```

## 🏗 Build for Production

```bash
npm run build
npm run preview
```

## 🌐 Languages Supported

| Code | Language | Direction |
|------|----------|-----------|
| `en` | English  | LTR       |
| `ar` | Arabic (MSA) | RTL   |
| `ru` | Russian  | LTR       |

Switch instantly via the **EN / AR / RU** toggle in the navbar.
